# SentinelGuard Insurance Company — Enterprise Cybersecurity Policy

## Project Overview

A comprehensive cybersecurity policy project developed for a simulated mid-sized insurance company. The project focuses on establishing a practical security governance and control framework for an environment with employee endpoints, customer-facing online services, cloud-based storage, and enterprise data-center infrastructure.

## Security Areas Covered

- Enterprise risk assessment
- Identity and Access Management (IAM)
- Multi-Factor Authentication (MFA)
- Customer and sensitive data protection
- Network and data-center security
- Cloud and online transaction security
- Application security and secure development
- Security monitoring and incident response
- Privileged Access Management (PAM)
- Data Loss Prevention (DLP)
- Security auditing and governance
- Regulatory and compliance considerations

## Frameworks and Standards Considered

- NIST Cybersecurity Framework (NIST CSF)
- CIS Controls
- PCI DSS
- NYDFS Cybersecurity Regulation (23 NYCRR Part 500)
- NAIC cybersecurity guidance

## Proposed Security Architecture

The policy incorporates a layered security approach using technologies and control categories such as next-generation firewalls, endpoint detection and response, SIEM, web application firewall, data loss prevention, and privileged access management.

## Project Purpose

The objective was to translate cybersecurity risks and regulatory requirements into practical policies, controls, responsibilities, and governance requirements suitable for a mid-sized insurance organization.

> This is a portfolio project and represents a simulated organizational environment. It does not claim implementation of the listed security technologies in a real insurance company.
